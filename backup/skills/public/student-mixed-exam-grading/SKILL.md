# 学生混合题型试卷批改技能（编排层）

## 技能定位

本技能用于处理一份文档内含多种题型的场景（如选择题+简答题+案例题+论述题）。
职责是编排，不是替代单题型评分骨架：

- 第 1 步：文档类型判别（先防误切论文）
- 第 2 步：分题切分（强边界切分 + 弱边界回并）
- 第 3 步：分题路由（每题只选一个主技能）
- 第 4 步：整卷汇总（总分、风险、可追溯说明）

---

## 最高优先级：read_file 硬规则

1. 允许读取：
   - 本技能 `SKILL.md`
   - 被路由到的题型技能 `SKILL.md`（`student-code/concept/case/essay/paper-report-grading`）
   - 反馈重批场景下可额外读取 `student-grading-feedback-revision/SKILL.md`
2. 禁止在 skills 目录盲搜并任意拼接技能规则；必须按本技能流程决定读取目标。
3. 若已误读无关技能，输出前忽略，仅按本技能与合法题型技能规则执行。

---

## 输出协议

- 全程仅 Markdown，禁止 JSON 与 ```json。
- 禁止输出思考独白或过程性口语（如“让我看看”“等等”“我再想想”）；仅输出结构化批改结果。
- 采用“双层交付”：
  1) **对话窗口概览版（简洁）**：仅输出以下内容，不展开长篇分析  
     - 学生必要信息（如姓名/学号/班级，若可见）  
     - 各题得分与小计（题号、满分、得分）  
     - 整卷总分  
     - 复核建议或风险提醒  
  2) **下载文件完整版（详细）**：输出完整整卷报告章节。
- 完整版整卷报告统一包含：
  - `## 【整卷评分与摘要】`
  - `## 【分题路由与得分明细】`
  - `## 【分题动态查证要点（汇总）】`
  - `## 【总体评价】`
  - `## 【改进建议】`
  - `## 【人工复核提示】`
- 先生成完整版并写入 `/mnt/user-data/outputs/student-mixed-exam-grading-report.md`（可加时间戳）并 `present_files`，再在对话窗口返回概览版。

### 执行风格约束（强制）

1. 一次性完成“判别 -> 切分 -> 路由 -> 评分 -> 汇总”，不要在回复中反复重述流程。  
2. 已确定分题路由后，不要再次讨论“是否应该读取技能”；直接按路由应用对应评分骨架。  
3. 同一技能文件不重复读取；同一结论不重复推翻与重算。  
4. 中间推理留在内心，最终仅交付可给教师直接使用的报告与必要复核提示。
5. 对话窗口默认走“概览版”，详细论证放在下载文件，不在窗口重复展开。

## 输入契约

最少输入：

1. 题目文档（试卷/课后题/作业文本）
2. 学生答案

可选输入：

- 教师评分标准
- 参考答案
- 每题分值
- 及格线（默认 60）

---

## 一、文档类型判别（DocumentTypeGate）

切题前必须先判别：

### A. 论文/报告体（paperLike）

若以下信号明显占优，直接走 `student-paper-report-grading`，不进入切题：

- 出现并成体系分布：摘要、引言、方法、结果、讨论、结论、参考文献
- 长段落学术叙述为主，非题目-作答交替结构
- 编号更像章节编号而非题号编号

### B. 试卷/作业体（examLike/homeworkLike）

若以下信号明显占优，进入切题：

- 存在题号或分题指令（Q1/Q2、1/2/3、一二三、（1）（2）等）
- 题目与答案呈分块对应
- 混有 ABCD、判断、简答、案例分析、论述等异构小题

### 判别仲裁

- 边界不清时默认保守：优先避免误切论文。
- 若判定为论文体但又有少量提问式文本，仅在 `【人工复核提示】` 标注，不切题。

---

## 二、分题切分（QuestionSegmentation）

### 1) 强边界切分（先切）

优先识别以下边界：

- `Q1/Q2/...`
- `一、二、三...`
- `1. 2. 3.`
- `（1）（2）...`
- 明显分隔线、题号标题

### 2) 弱边界回并（再合）

若片段满足任一条件，回并邻近片段：

- 仅有选项（ABCD）但无题干
- 片段过短且无法独立评分
- 上下文强依赖（如“续上题”“结合前文”）

### 3) 切分置信度

每个分题输出 `segment_confidence`（高/中/低）：

- 高：题号边界明确且题干答案完整
- 中：边界清楚但题干或答案轻微缺失
- 低：依赖推断合并才形成分题

低置信分题必须在整卷 `【人工复核提示】` 汇总。

---

## 三、分题路由（PerQuestionSkillRouter）

每个分题只选一个主技能，不做多技能并行打分，避免漂移。

### 路由优先级（默认）

1. 编程/算法实现 -> `student-code-questions-grading`
2. 概念/名词解释/简答/填空/客观题 -> `student-concept-questions-grading`
3. 案例分析问答 -> `student-case-questions-grading`
4. 论述/观点评析 -> `student-essay-questions-grading`

### 路由信号

采用“双信号”判断：

- 题干指令词（如“分析案例”“论述”“实现函数”“选择正确选项”）
- 学生答案形态（代码块、要点式短答、案例论证、议论文式长文）

### 冲突仲裁

- 若同题出现多信号，按“主要交付物形态”选择一个主技能。
- 若路由置信度低，在分题明细中标注 `route_confidence=低` 并建议人工复核。

### 路由后执行规则（强制）

1. 对每个分题仅应用一个主技能评分骨架。  
2. 单题先得出“标准化题内分”（0-100），再按该题满分折算。  
3. 不在报告中展开冗长草算过程；仅保留关键依据、题内分、折算分。  
4. 单题评分完成后不回头重写前题，除非发现明确事实错误。

---

## 四、整卷汇总（ScoreAndReportAggregator）

### 分数聚合规则

1. 若题目给出每题分值，按题目分值汇总总分。
2. 若仅有总分无分题分值，分题先按等权，再折算到总分。
3. 若无任何分值信息，默认整卷满分 100，分题等权汇总。
4. 单题型技能内部维度分只用于该题论证，不在整卷层重复造维度。

### 可追溯字段（必须输出）

每题至少输出：

- 题号/片段标识
- 命中技能
- `segment_confidence`
- `route_confidence`
- 该题得分与满分
- 一句话评分依据

### 数值输出约束

- 小题得分可保留 1 位小数；整卷总分取整数（四舍五入）。  
- 在 `【分题路由与得分明细】` 使用统一表格输出，避免段落式重复解释。  
- 计算链路必须前后一致：分题折算之和 -> 整卷总分，不得出现两套口径。

### 复核触发

满足任一触发人工复核：

- 存在低置信切分或低置信路由
- 分题材料缺失（题干或答案不完整）
- 题号边界明显歧义且影响得分

---

## 反馈重批机制（自然语言）

遵循统一反馈重批协议：

- 支持按“题号 / 题型 / 全卷”粒度重批
- 未点名分题保持稳定，避免整卷无关漂移
- 重批时先输出 `## 【反馈理解与本轮调整】` 再输出完整整卷报告

---

## 质量守卫（内心自检）

- 无 JSON
- 先判别文档类型，再决定是否切题
- 论文体不误切
- 每题仅一个主技能
- 分题明细含可追溯字段
- 低置信项有人工复核提示
- 不输出思考独白与反复自我确认文本

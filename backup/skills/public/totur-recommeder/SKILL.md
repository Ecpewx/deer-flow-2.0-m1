# 导师推荐技能

## 何时使用
- 用户需要按研究方向、关键词、学院或职称查找导师
- 用户希望比较候选导师并获取推荐理由

## 输入建议
- `query`: 用户研究兴趣或需求（必填）
- `k`: 推荐数量，默认 5，范围 1-20
- `filters.school`: 学院/学校关键字（可选）
- `filters.title`: 职称关键字（可选）
- `filters.has_papers`: 仅返回有论文导师（可选）
- `filters.has_projects`: 仅返回有项目导师（可选）

## 执行规范
1. 调用后端导师推荐接口获取候选列表
2. 若 LLM 理由不可用，自动使用规则理由（不可中断主流程）
3. 结果按 `score` 从高到低输出

## 输出格式
请输出结构化 Markdown：
- 查询词
- 推荐导师列表（序号）
  - 姓名、职称、单位
  - 研究方向
  - 匹配分
  - 推荐理由
  - 联系方式（邮箱/主页，如有）
  - 论文与项目计数

## 约束
- 不杜撰导师信息
- 无命中时明确告知并建议调整关键词或筛选条件
